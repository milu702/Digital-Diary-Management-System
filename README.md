# Digital Diary Management System

## About the Project
The Digital Diary Management System is an Android application that allows users to write, save, view, update, delete, and search personal diary entries.

## Features
- Add diary entries
- View saved entries
- Edit existing entries
- Delete diary entries
- Search diary entries
- Store diary data using SQLite database

## Technologies Used
- Java
- XML
- Android
- SQLite

## Database
The application uses an SQLite database named `PersonalDiary.db` to store diary entries. Each entry contains a title, content, and date.

## Package Name
`com.example.personaldiary`

## Project Status
Source code and project configuration files are being added to GitHub. The application has not yet been built or tested in Android Studio.
